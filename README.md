## `01` — Sobre mim

Sou estudante de **Ciência da Computação na UNIJORGE**, com conclusão prevista para 2027, interessado em desenvolver soluções de software e explorar o potencial dos dados.

Tenho direcionado meus estudos para duas áreas que considero complementares: **desenvolvimento Back-End**, com foco na construção de aplicações, APIs e integração com bancos de dados, e **análise de dados**, utilizando programação para explorar informações e extrair insights.

Gosto de aprender colocando a mão na massa. Por isso, utilizo projetos práticos para consolidar conhecimentos, experimentar tecnologias e evoluir como desenvolvedor.

- 🎓 Ciência da Computação — UNIJORGE
- 💻 Foco profissional: Back-End e Análise de Dados
- 🧩 Interesse em desenvolvimento de software, bancos de dados e exploração de dados
- 🚀 Objetivo: transformar aprendizado em experiência prática e soluções reais
